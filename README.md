# AI Linux Automation Suite

An AI-powered Linux automation suite built using **Bash scripting** to monitor system health, network status, security posture, log analysis, and automated backups — designed with **real-world DevOps practices** in mind.

---

## 🚀 Features

### 🖥️ System Health Monitoring
- CPU, memory, disk usage checks
- Uptime and load monitoring
- Automated health reports

### 🌐 Network Monitoring
- Internet connectivity check
- DNS resolution validation
- Latency measurement
- Network health report generation

### 🔐 Security Auditing
- Open listening ports audit
- Sudo-enabled users audit
- SSH login analysis
- Security risk reporting

### 📄 Log Monitoring
- Syslog error and warning analysis
- SSH failed login detection
- AI-generated incident summaries

### 💾 Automated Backup System
- Config-driven backup paths
- Compressed `.tar.gz` backups
- Retention-based cleanup
- Backup integrity reporting
